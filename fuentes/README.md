# Fuentes

Material de origen del proyecto. **Nada de esta carpeta se publica**: el sitio
servible es la raíz del repo (`index.html`, `support.js`, `assets/`).

| Carpeta | Qué contiene |
|---|---|
| `diseno/` | `BRASANTO - Web.html` — export autocontenido de Claude Design. De aquí se extrajo el sitio de la raíz. |
| `fotos-originales/` | Fotografía original en JPG, antes de entrar al diseño. |
| `fotos-zip/` | Entregas comprimidas de fotografía en alta. |
| `video/` | Clips de hero y material en bruto. |
| `referencias/` | Capturas, variantes de color, análisis de competencia, imágenes de apoyo. |
| `versiones-previas/` | Iteraciones anteriores de la web (`website/`, `index_1.html`). |

## Notas

- **`diseno/BRASANTO - Web.html` es una versión anterior**, no `BRASANTO Web v2.dc.html`.
  Le falta la sección «Para picar» y el resto de la carta ampliada de v2.
  v2 sigue solo en Claude Design (proyecto `6afc9979-4838-44dc-a2fd-2edd14b4a653`).
- Se omitió `HEROVIDEOPOLLO.rar`: es el mismo contenido que
  `video/HEROVIDEOPOLLO.mp4`, ya incluido.
- Los duplicados exactos entre carpetas no ocupan espacio extra: git guarda cada
  blob una sola vez por hash.
- `video/videoplayback.mp4` es material de referencia de terceros. No usarlo en
  producción sin verificar derechos.
